# AlgoLens – Interactive Algorithm Visualizer

**Understand Algorithms. Visualize Their Execution. Analyze Their Complexity.**

AlgoLens is a Java-based interactive learning application designed to help students understand how algorithms work through step-by-step explanations, visual demonstrations, and complexity analysis.

## Features

### 1. Sorting Algorithms

Explore five popular sorting techniques:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

**Features include:**
- Custom array input
- Step-by-step execution
- Animated sorting visualization
- Previous, Next, Play, Pause and Reset controls
- Comparison and operation counters
- Best, average and worst-case time complexity
- Space complexity information

### 2. Searching Algorithms

Learn two fundamental searching techniques:

- Linear Search
- Binary Search

**Features include:**
- Custom array and target input
- Step-by-step search trace
- Comparison counter
- Search result and element position
- Time and space complexity information

### 3. Graph Algorithms

Explore five important graph algorithms:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's Algorithm
- Prim's Algorithm
- Kruskal's Algorithm

**Concepts covered:**
- Graph traversal
- Shortest-path algorithms
- Minimum Spanning Trees (MST)
- Queue, stack and priority queue concepts
- Graph time and space complexity

### 4. Complexity Analysis

Understand how algorithm performance changes with input size.

**Topics include:**
- Best-case time complexity
- Average-case time complexity
- Worst-case time complexity
- Auxiliary space complexity
- Big-O notation
- Comparison of sorting algorithms

## Technologies Used

- **Programming Language:** Java
- **GUI Framework:** JavaFX
- **Build Tool:** Apache Maven
- **Development Environment:** JDK 21

## Getting Started

### Prerequisites

Make sure you have the following installed:

- JDK 21 or later
- Apache Maven

### Run the Project

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd AlgoLens
```

**3. Run the application**

```bash
mvn clean javafx:run
```

## Project Objective

AlgoLens aims to make algorithm learning more interactive and intuitive.

Instead of focusing only on theoretical definitions and final outputs, the application helps students understand the internal working of algorithms through visual representations, execution steps and performance analysis.
